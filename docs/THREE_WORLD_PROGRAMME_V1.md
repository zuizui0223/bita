# Three-world trait-architecture programme

## Chapter order

```text
Chapter 1 / SCH
shared-coordinate world
-> establish causal conflict and locate compromise

Chapter 2 / BALANCE
middle world
-> conflict is real, but differentiated architecture still does not pay
-> quantify domain position, depth, reserve, topology, and persistence

Chapter 3 / BITA
differentiated-coordinate world
-> determine when additional dimensionality wins and identify its mechanism
```

## Programme numbering versus legacy package labels

BITA is now **Chapter 3 at the programme level**. Some validated submission-package filenames, audit receipts, and text generated before the BALANCE repository was separated still contain the historical label `Chapter 2`. Those strings are provenance labels for an already-QA'd package, not the current programme order.

Do not mass-rename those package surfaces inside this framing change. A later package-renumbering pass must rebuild and visually QA the complete submission artifact before the legacy labels are removed.

## BITA-facing interface

BITA owns the differentiated-world comparison. In the general bridge,

```text
R >= 0
Delta_arch = R-K
```

and in the quadratic corollary,

```text
R = sL.
```

The BITA-facing architecture boundary is therefore

```text
Phi = sL-K = 0.
```

BITA does not own the left-hand conflict boundary `L=0`; that geometry comes from SCH.

## Handoff from BALANCE

BALANCE occupies

```text
L > 0 and Phi < 0.
```

It should pass to BITA a matched context with, where available:

- the SCH-derived fitness-scale conflict budget `L`,
- the BALANCE reserve `rho = K-sL`,
- middle-world position and two-sided depth,
- uncertainty on the architecture margin,
- the environmental or experimental context defining that location.

BITA then asks what happens at and beyond the right-hand boundary:

```text
Phi = 0  architecture critical interface
Phi > 0  differentiated architecture favoured.
```

## Direct worldline check

When both architectures can be optimized on the same reproductive fitness scale, define

```text
W_S* = optimized shared-world fitness
W_D* = optimized differentiated-world fitness
Delta_W = W_D*-W_S*.
```

The programme expects, under the declared decomposition,

```text
Delta_W = sL-K.
```

A mismatch is a bridge failure to investigate, not a quantity to average away. It may reflect scale mismatch, omitted channels, context mismatch, or a genuine change in the fitness landscape after differentiation.

## What remains BITA-specific

BITA continues to own:

- architecture gain and partial decoupling,
- dimensional release,
- architecture-cost comparisons,
- mechanism identification after multiple axes exist,
- the floral interaction-identification worked case.

BALANCE does not claim these mechanisms merely because a system lies near `Phi=0`.

## Claim boundary

Crossing into `Phi>0` establishes a present-day architecture comparison under the registered model. It does not by itself establish historical splitting or macroevolutionary modularization.
