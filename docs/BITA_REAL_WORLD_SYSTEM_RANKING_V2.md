# BITA real-world system ranking v2

## Ranking principle

Systems are not ranked by how many papers exist. They are ranked by which Chapter-2 identification level they most directly support.

```text
D0  distinct coordinates
D1  preferential functional loading
D2  dimensional / outcome release
D3  mechanism-resolved differentiation
D4  stable partial or strong modularity
D5  historical modularization.
```

No current system closes D0-D3 from one identified SCH compromise in one experiment.

## Rank 1 for D1 — Pedicularis rex

### Architecture

```text
x-like coordinate = corolla exsertion / exposure geometry
y-like coordinate = water-retention state of cupulate bracts
function 1        = pollination
function 2        = seed-predator protection.
```

The 2016 study recovers the shared conflict:

```text
exsertion -> pollen arrival: positive
exsertion -> seed predation: positive
seed predation -> final viable seeds: negative.
```

The 2015 water-removal experiment then provides a strong y-loading test.

Pollinator visitation:

```text
beta = 0.012
SE   = 0.224
P    = 0.958.
```

Initial seed set:

```text
beta = 0.001
SE   = 0.006
P    = 0.906.
```

Seed predation:

```text
beta = -0.072
SE   = 0.007
P    < 0.0001.
```

Final seed set:

```text
beta = 0.025
SE   = 0.006
P    < 0.0001.
```

The source states that draining water increased seed predation, and the treatment effect was significant in 5/6 populations.

Interpretation:

```text
y strongly loads on antagonist protection
while the measured pollinator-visitation cross-effect is near zero.
```

Current status:

```text
STRONGEST_REAL_WORLD_D1_PREFERENTIAL_LOADING_ANCHOR
PARTIAL_MODULARITY_NOT_COMPLETE_MODULARIZATION
```

Why only partial modularity: exsertion itself depends partly on bract height, and the defence state is also produced by the bract. Functional mechanisms are separated more than the underlying structure.

## Rank 1 for D2 local release — Nicotiana attenuata / Kessler 2008

The manipulated attraction-by-defence-like factorial remains the strongest current local release anchor.

```text
x = attraction / benzylacetone-like axis
y = antagonist-reducing / nicotine-like axis
```

Recovered status:

```text
A1 positive across registered aggregate-compatible bounds
A0 near and spanning zero
aggregate Delta_AD sign positive
source/design uncertainty unresolved
systemic defence manipulation caveat retained.
```

Current interpretation:

```text
INTERACTION_LEVEL_RELEASE_ANCHOR
NOT_COMPLETE_DIMENSIONAL_RELEASE
NOT_MECHANISM_RESOLVED_DIFFERENTIATION.
```

Nicotiana is stronger than Pedicularis for D2 because it contains an explicit manipulated x-y reproductive surface, but weaker for clean D1 preferential loading because the defence manipulation is systemic and pollinator interference is not fully isolated.

## Strongest D3 component evidence — route-separation systems

The route ledger and selective intervention literature recover complementary mechanism faces:

```text
antagonist relief
pollinator interference
separated effective domains
overlapped domains
bypassable defence
conditional / temporal gating.
```

These studies show why some second axes function preferentially and others remain cross-coupled.

However:

```text
no screened system point-identifies rho_delta + iota_delta + independent joint cost
in one complete x-y-function1-function2 design.
```

Current status:

```text
D3_COMPONENTS_RECOVERED_ACROSS_SYSTEMS
D3_COMPLETE_CHAIN_NOT_RECOVERED.
```

## Component-partitioning anchor — Petunia

Targeted floral-scent perturbations show different bouquet components carrying different ecological roles.

This is useful evidence for:

```text
component functional differentiation
```

but not yet for:

```text
release from an identified shared-trait compromise on common reproductive fitness.
```

## Conditional-gating anchor — Biscutella / related systems

Conditional cue deployment demonstrates another solution to multifunctional conflict:

```text
not necessarily split the cue into permanent traits
but regulate when / under which state it is exposed.
```

This is an architecture-level alternative to strict modularization and should remain in BITA as a partial-separation solution.

## New programme implication

Pedicularis and Nicotiana are complementary rather than competing anchors.

```text
Pedicularis:
shared conflict
-> selective y effect with very low detected pollinator cross-effect
-> missing x-y optimum-release surface

Nicotiana:
shared attraction axis
-> explicit x-y reproductive interaction
-> missing clean preferential loading / full allocation.
```

Together they define the exact experimental gap BITA must close:

```text
one system
+ identified SCH compromise
+ validated preferential y loading
+ multi-level x-y optimum release
+ common fitness gain
+ selective mechanism allocation.
```
