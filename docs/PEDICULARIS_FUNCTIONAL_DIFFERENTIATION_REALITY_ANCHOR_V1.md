# Pedicularis rex functional-differentiation reality anchor v1

## Purpose

This note places `Pedicularis rex` in the generalized Chapter-2 architecture.

Two separate studies in the same species provide complementary evidence:

- Sun, Armbruster & Huang 2016, Annals of Botany, DOI `10.1093/aob/mcw097`
- Sun & Huang 2015, AoB PLANTS, DOI `10.1093/aobpla/plv019`

They must not be merged as though they were one factorial dataset.

## Shared conflict inherited from Chapter 1

The 2016 study identifies a conflicted display/protection geometry:

```text
x-like coordinate = corolla exsertion above the water-bearing cupulate bract.
```

Greater exsertion was positively associated with stigmatic pollen load, but also with seed predation. Seed predation reduced final viable seed production.

Thus the same geometric direction is favored by pollination and opposed by seed-predator protection.

This is a strong observational shared-conflict anchor, not a manipulated dimensional-release surface.

## Candidate second functional axis

The 2015 experiment manipulated:

```text
y-like coordinate = water-retention state of the cupulate bract
```

by draining bracts before anthesis and comparing them with intact controls.

The intervention showed strong preferential loading on antagonist protection.

### Function-1 cross-effect

Pollinator visitation showed essentially no treatment response:

```text
beta = 0.012
SE   = 0.224
chi2 = 0.003
P    = 0.958.
```

Initial seed set was also unchanged:

```text
beta = 0.001
SE   = 0.006
chi2 = 0.014
P    = 0.906.
```

### Function-2 target effect

Seed predation changed strongly:

```text
across-site treatment effect:
beta = -0.072
SE   = 0.007
chi2 = 92.808
P    < 0.0001.
```

The source states that draining the bracts increased seed predation, so retained water is the protective state.

The treatment effect was significant in 5 of 6 populations.

Final seed set also changed:

```text
beta = 0.025
SE   = 0.006
chi2 = 16.710
P    < 0.0001.
```

## BITA response-matrix interpretation

At the level supported by these experiments:

```text
                 function 1              function 2
                 pollination             seed-predator protection
x = exsertion    positive / strong       conflicted exposure route
y = bract water  ~0 visit effect         strong protection effect
```

This is unusually close to preferential functional loading:

```text
|y -> function 2| >> |y -> function 1|
```

on the measured ecological responses.

## Why this is partial rather than complete modularity

The two functional axes are not developmentally independent in a strict sense.

Corolla exsertion is defined using cupulate-bract height, while water-based protection is also supplied by the bract structure. The architecture therefore separates the functions mechanistically while retaining structural coupling.

Best interpretation:

```text
PARTIAL_FUNCTIONAL_DIFFERENTIATION_REALITY_ANCHOR
```

This is valuable for BITA because the theory does not require perfect modularity; it predicts a continuum from integrated shared architecture to increasingly preferential loading.
