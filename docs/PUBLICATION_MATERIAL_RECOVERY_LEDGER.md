## Stop rule

Additional broad evidence hunting is not required to make the current BITA claim set valid. New material is admitted only if it fills a declared matrix cell, corrects a source classification, or changes the minimum-augmentation conclusion. Weak, null, unavailable and non-identifiable results remain preserved.
