# PR #183 disposition audit v1

## Decision

PR #183 (`program/theory-causal-generality-v1`) must **not** be merged into the current BITA paper.

The current BITA ownership is:

```text
trait interaction != ecological mechanism
```

and current `main` already contains the active identification paper, the 56-route / 25-cluster literature synthesis, the 17-system high-information frontier, compatible route-level quantitative lanes, and a final same-system mechanism-allocation experiment retained as the last identification upgrade.

PR #183 instead contains an older architecture-value / decoupling programme whose central objects include coupling recovery, architecture value, decoupling gain, critical budgets, cost allocation, reachability, and value-function geometry. Those objects now belong primarily to the companion SLK architecture-value spine rather than the active BITA novelty claim.

## Preserve, do not merge

The source branch is retained as provenance. Closing the PR does not delete the branch or its commits.

Do not bulk-copy the branch into BITA `main`, because doing so would reintroduce a second incompatible paper identity and blur the current SCH -> SLK -> BITA ownership boundary.

## Handoff rule

Any future port from #183 must be selective and ownership-aware:

```text
architecture value / decoupling theorem -> review for SLK
mechanism allocation / identified-set result -> compare against current BITA before porting
Pedicularis logistics -> reuse only if compatible with current final identification design
obsolete duplicated paper routing -> archive only
```

No #183 file should be promoted merely because it is mathematically valid; it must first match the ownership boundary of the destination paper.
