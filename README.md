# Biotic Interaction Trait Architecture (BITA)

BITA's **primary forward paper** is now the macro-ecological floral-defence selectivity / access-routing synthesis.

## Current thesis

> **Floral defence selectivity is a trait × consumer × context state generated by unequal access and exposure of antagonists and mutualists.**

The central ecological mechanism is an effective-exposure window. For defence/access intensity `x`,

```text
z_H = q_H x
z_P = q_P x

x_H* = tau_H / q_H
x_P* = tau_P / q_P
```

A selective window exists when

```text
x_H* < x < x_P*
```

so antagonist suppression begins before pollinator interference. Domain overlap can close that window; bypass can defeat the focal defence; increasing exposure can move a system from ineffective to selective to interfering; and access barriers can reroute exploitation toward bypass/robbing rather than eliminate it.

## Current evidence architecture

The active paper triangulates four layers:

1. **Broad D-side route corpus** — 17 unique study programs after DOI-level deduplication: chemical 9, physical 7, reward/access 1; 10 include same-study pollinator follow-up.
2. **Matched-D state recovery** — 11 scorable historical + systematic-expansion systems align with the frozen separated / transitional / overlapped qualitative state mapping. The strict direction-supported Stage-2 comparison remains `n=3` and descriptive only.
3. **Within-D conditionality** — 8 independent systems show switching with dose/expression, cumulative exposure, consumer identity, response stage, or timing.
4. **Community-scale access routing** — two independent public-data analyses recover the same qualitative direction:
   - Sakhalkar insect–flower network: 57 cheating-exposed plant species, Spearman `rho=0.346786`, permutation `p=0.0086`;
   - Aubert/EPHI Ecuador extension: 1,378 bird × plant × site units, robbery `0.30698` under tube>bill barrier vs `0.08139` when accessible, mismatch `rho=0.41826`, permutation `p=0.0001`, with 15/17 comparable sites in the same direction.

The paper-level conclusion is therefore:

```text
UNEQUAL ACCESS / EXPOSURE
        ->
SELECTIVE WINDOW / INTERFERENCE / BYPASS
        ->
CONTEXT-DEPENDENT FLORAL DEFENCE
        +
EXPLOITATION ROUTING
```

## Claim boundaries

Do not infer:

- natural prevalence from the screened literature corpus;
- `domain > modality` from the strict `n=3` comparison;
- equivalence from null-compatible pollinator outcomes;
- causality from either community network analysis;
- a unique tube-length effect in the Sakhalkar network after correlated morphology is considered;
- a common pooled effect size across the two networks;
- universal empirical values of `q_H`, `q_P`, `tau_H`, or `tau_P`.
