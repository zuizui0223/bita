# Universal-rule falsification protocol v1

## Purpose

Do not promote the mechanism-first empirical synthesis to a final paper conclusion merely because many examples can be narrated post hoc. The leading candidate rule must outperform plausible simpler alternatives on supporting, switching, and failure cases.

## Candidate rules

### R0 — universal sign

Attraction and defence have one recurrent positive or negative association.

### R1 — defence-strength rule

The realised state is determined mainly by how strong D is. Stronger D should systematically move systems in one direction regardless of consumer identity, access route, space, or time.

### R2 — implementation-class rule

Chemical and physical defences have different characteristic effects; selectivity is primarily a property of defence class.

### R3 — effective-domain separation rule

The realised state depends on whether antagonist and pollinator channels experience the focal D in separable effective domains. The separating coordinate can be consumer susceptibility, dose/exposure threshold, attack route, spatial position, developmental time, visitor functional mode, or response stage.

Predictions:

```text
antagonist affected + pollinator spared      -> selective / guarded state
antagonist affected + pollinator also affected -> overlapping-domain / interference state
antagonist bypasses or tolerates D            -> D channel fails
changing consumer or exposure can switch state without changing D identity
```

## Falsification criteria for R3

R3 should be weakened or rejected if any of the following recur:

1. systems with clearly separated antagonist/pollinator exposure domains repeatedly show strong pollinator interference;
2. systems with strongly overlapping exposure domains repeatedly show guarded states without another demonstrated separating coordinate;
3. consumer identity changes the A×D sign while measured D sensitivity/use remains the same across consumers;
4. physical and chemical systems require incompatible rules rather than the same abstract separation logic;
5. failure cases cannot be classified prospectively as overlap, bypass/tolerance, or absence of a validated D channel.

## Test set

Use source-adjudicated systems already recovered under the registered evidence program. Do not choose only supporting cases.

High-information cases:

- Catalpa — chemical consumer selectivity;
- Polemonium — dose-dependent closure of a selective window;
- Aconitum — different antagonist and pollinator response thresholds;
- Pedicularis — attack-mode selectivity;
- Thunia — visitor functional-mode routing;
- Codonopsis — spatial access separation;
- Chrysothemis — developmental-time / attack-route separation;
- Bejaria — broad physical filter / non-selective boundary case;
- Salvia — antagonist bypass / failed anti-robber channel;
- Rivest Lupinus pollen chemistry — defence-like chemistry without a clean focal antagonist-reduction channel;
- Kessler 2015 Nicotiana — crossed A × D architecture with consumer-specific sign reversal.

## Comparison logic

For each case, code *before interpreting the outcome*:

- D implementation class;
- antagonist effective exposure to D;
- pollinator effective exposure to D;
- demonstrated separating coordinate, if any;
- expected R3 state: selective / overlap / bypass-channel-failure / unresolved.

Then compare that expectation with the reported antagonist and pollinator outcomes. R0-R2 are evaluated against the same cases.

## Promotion gate

The final conclusion may be promoted only if:

1. R3 explains independent chemical and physical systems;
2. R3 predicts both guarded and interference states;
3. R3 accommodates explicit failure/bypass cases without redefining D after seeing the outcome;
4. direct crossed-trait evidence is directionally consistent with the same consumer-specific logic;
5. no simpler rule (R0-R2) explains the full test set equally well;
6. residual contradictions are listed rather than hidden.

Until this gate is passed, PR #129 remains scientific work in progress and manuscript/submission finishing is blocked.
