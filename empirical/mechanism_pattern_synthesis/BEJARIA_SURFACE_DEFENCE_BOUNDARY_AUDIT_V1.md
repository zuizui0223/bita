# Bejaria surface-defence boundary audit v1

## Purpose

Test the physical/surface selectivity hypothesis against a case where flower-specific defence may be **non-selective** across insect visitors.

Primary source: Chautá et al. 2022, *Scientific Reports* 12:19848, DOI `10.1038/s41598-022-23261-2`.

## Strong focal D evidence

`Bejaria resinosa` stickiness is expressed on petals/sepals and has a direct florivore-reducing function.

Manipulative field result:

```text
sticky control flowers damaged:       0% observed
MeOH-washed flowers damaged:          21% on average
fruit set after MeOH washing:         32.5% lower than sticky controls
X2 = 4.877, df=1, P=0.027
```

Thus the flower-specific D gate is strong.

## Why this is a boundary case for guarded defence

The source explicitly notes that sticky flowers efficiently exclude **insect interactions both mutualist and antagonist**. This differs from the spatially selective Codonopsis surface where the pollinator foothold is preserved.

The authors hypothesized that hummingbird pollination might allow sticky plants to retain defence benefits while bypassing costs to insect pollinators. Their bird-exclusion experiment did not support a simple version of that mechanism:

```text
bird-exclusion effect on fruit set:  X2=2.1817, df=2, P=0.3359
stickiness effect:                   X2=5.944, df=2, P=0.051
stickiness x bird-exclusion:         X2=1.45, df=2, P=0.22
```

The absence of the predicted interaction means this system must not be coded as a clean pollinator-guild-selective guarded state.

## Mechanism-first interpretation

Bejaria supplies a useful falsification/boundary condition:

> a flower-specific surface defence can be highly effective against florivores yet remain broad enough to interfere with mutualistic insects; alternative pollinator guilds do not automatically rescue the cost.

This supports the selectivity-window framework precisely because it shows that **physical D is not inherently selective**. Spatial or consumer separation must actually be demonstrated.

Contrast:

```text
Codonopsis: ant-access surface slippery + pollinator foothold non-slippery -> spatially selective
Bejaria: sticky flower surface can exclude insects in both roles -> non-selective surface filter
```

## Universality role

```text
U3 defensive efficacy:              strong supporting system
U5 guarded/selective defence:       boundary / falsification case
U6 switching-rule interpretation:   supports need for actual domain separation
strict A x D:                       no
W_AD:                               not identified
```

## Inference boundary

```text
higher fruit set under sticky control != W_AD
bird-exclusion null != hummingbirds irrelevant generally
surface defence != physical selectivity automatically
one non-selective system != rejection of guarded-defence recurrence
```
