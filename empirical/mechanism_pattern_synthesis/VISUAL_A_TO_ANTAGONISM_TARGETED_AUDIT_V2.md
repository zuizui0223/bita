# Visual A -> antagonism targeted audit v2

## Purpose

Strengthen U2 outside floral scent by prioritizing manipulated or source-quantified visual display axes that are used by both mutualists and antagonists.

## 1. Dalechampia scandens — quantitative visual same-axis anchor

Primary source: Perez-Barrales et al. 2013, DOI `10.1111/j.1600-0706.2013.20780.x`.

The same showy involucral bract area axis predicts both pollinator use and seed predation.

Source-translated +1 SD bract-area change:

```text
pollinator patch visitation: 83.1% -> 94.4%
seed predation:              ~0.2% -> ~2.5%
```

This is the current strongest non-scent quantitative same-axis visual anchor. The source-reported probability translations are retained rather than reverse-engineered into an uncertainty-bearing coefficient without the original covariance/model object.

## 2. Hibiscus moscheutos — direct petal-size manipulation

Primary source: Kudoh & Whigham 1998, DOI `10.1007/s004420050633`.

Three petal-size treatments (0%, 50%, 100% radius reduction) directly tested the visual display axis.

Key source results:

- legitimate pollinators ignored flowers with petals completely removed;
- complete petal removal strongly reduced female reproductive success through pollen-deposition failure;
- adult pollen predator `Althaeus hibisci` was denser on intact/larger-petal flowers;
- petal size did not alter later seed predation, demonstrating response-stage specificity within the antagonist lineage.

This is experimental cross-role tracking on a visual A axis, but the publicly recovered abstract does not supply enough group-level uncertainty to reconstruct a canonical cross-study effect size.

## 3. Ipomopsis aggregata — experimental floral-display replication

Primary source: experimental manipulation of inflorescence flower number (Oecologia; PubMed record PMID 28307472).

Source-adjudicated results:

```text
larger displays -> more likely first visited by hummingbird pollinators (P < 0.01)
larger displays -> more total flower visits
larger displays -> greater pre-dispersal seed predation (P < 0.001)
```

This supplies a second independent manipulated visual/apparency system in which a larger floral display is tracked by both mutualists and antagonists.

It is not converted into an uncertainty-bearing meta-analytic effect because the accessible source record does not provide the group counts/SE structure needed for a defensible reconstruction.

## 4. Boundary systems

- `Eurya japonica`: flower size increased visitor number but did not affect florivory frequency; useful evidence that visual apparency is not universally tracked by antagonists.
- `Hibiscus`: adult pollen-predator tracking did not propagate to later seed predation; outcome stage matters.

## U2 adjudication

The non-scent evidence now supports **recurrent cross-modal shared tracking** across:

```text
visual bract area
petal size
whole floral display size
petal colour
combined colour + scent axes
```

The strongest current claim remains recurrence, not a universal visual `A -> antagonism` effect magnitude.
