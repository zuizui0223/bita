# Mechanism-first universality protocol v1

## Purpose

This protocol replaces a conventional **Pattern -> Mechanism** discovery sequence with the design actually used by this project:

```text
Part I: Mechanism first
derive admissible mechanism balances and conditional sign transitions

Part II: Universality test
ask whether those predicted routes and transitions recur independently in nature
```

The empirical endpoint is therefore not a single grand mean and not maximum study count. It is the **replication and cross-system universality of theory-predicted mechanism/state classes**.

## Fixed theory-facing predictions

After the orientation gate, the theoretical sign is organised as:

```text
W_AD = rho - iota - kappa
```

with antagonist relief (`rho`), pollinator/mutualist interference (`iota`), and direct joint-cost curvature (`kappa`) kept distinct.

The empirical universality test is organised around the following predictions.

### U1 — antagonist cost / relief opportunity

Antagonist pressure or exploitation should recurrently reduce floral reward, legitimate pollination, or reproductive output, creating a real opportunity for antagonist relief.

### U2 — shared attraction tracking

Attraction traits/signals should not be assumed mutualist-specific. Antagonists may repeatedly track the same sensory/display axes used by pollinators.

### U3 — defensive efficacy

Flower-specific defence/access-limitation traits should recurrently suppress antagonist use, damage, or access across distinct defence mechanisms.

### U4 — pollinator interference is conditional, not universal

The same defence trait can impose a pollinator cost in some contexts but not others. A universal negative `D -> pollination` effect is therefore not required by the theory.

### U5 — interaction selectivity / guarded defence

Consumer-, attack-mode-, space-, time-, body-size-, or lifecycle-selective defence should permit antagonist suppression while preserving legitimate pollination/function more often than non-selective defence.

This is the strongest current candidate empirical axis linking Part II back to the theoretical balance.

### U6 — recurrent state transitions

Dose/intensity, consumer identity/function, resource/exposure, tissue/attack mode, response stage, spatial/temporal access, population/site, and lifecycle stage should repeatedly switch effect state or sign across independent systems.

### U7 — direct `A x D` sign

A direct attraction x defence interaction must be estimated by a shared-unit/factorial or otherwise identifying design. Marginal recurrence cannot substitute for this prediction.

### U8 — direct joint cost

`kappa` requires a strict direct joint-cost estimate. Separate attraction costs, defence costs, trait covariance, or ecological interference cannot be combined to identify it.

## Replication status vocabulary

Each prediction receives exactly one current status:

- `RECURRENT_STRONG`: replicated in multiple independent biological systems and across more than one mechanism/modality where relevant; quantitative synthesis exists or source-level direction is unusually consistent.
- `RECURRENT_PROVISIONAL`: replicated in multiple independent systems, but quantitative comparability or breadth remains limited.
- `CONDITIONAL_RECURRENT`: both effect and null/opposite states recur, with repeated context axes suggesting a structured moderator rather than one universal sign.
- `WEAK`: one or two independent systems or narrow mechanism coverage.
- `CONTRADICTORY_UNRESOLVED`: recurrent evidence exists but no stable mechanism-level moderator yet explains conflicting states.
- `UNIDENTIFIED`: the required identifying design/effect scale is absent or insufficient.

No status is a prevalence estimate.

## Breadth dimensions

For each prediction, record independent breadth across:

1. plant systems/taxa;
2. attraction modality (`scent`, `colour`, `visual display`, `reward`, other);
3. defence mechanism (`chemical`, sticky/slippery surface, hairs, liquid barrier, bract/access barrier, temporal/spatial filtering, other);
4. antagonist guild/attack mode;
5. pollinator guild/function;
6. response stage (`arrival`, visitation, handling, exploitation, damage, pollen transfer, reproduction);
7. ecological context axis.

Breadth is used as evidence of universality only when the underlying systems are independent.

## Quantitative priority

The next quantitative target is not a pooled `W_AD`. It is a matched defence-study architecture:

```text
same focal D study
  -> D -> antagonist effect
  -> D -> legitimate-pollinator effect
```

When compatible scales/designs permit, calculate an oriented study-level selectivity contrast:

```text
selectivity = antagonist suppression - legitimate-pollinator suppression
```

The exact effect metric must be defined within each compatible lane before subtraction. Standardized effects cannot be combined merely because signs are available.

Primary moderators to test:

- chemical vs physical defence;
- consumer-selective vs non-selective defence;
- attack-mode selectivity;
- spatial/temporal targeting;
- dose/intensity;
- response stage;
- pollinator guild/function.

## Search priority

Targeted searches should now be prediction-led rather than class-accumulation-led.

Highest priority:

1. paired/matched `D -> antagonist` + `D -> pollinator` effects from the same study;
2. factorial/shared-unit `A x D` designs;
3. direct joint-cost estimates;
4. quantitative `A -> antagonism` effects across visual, scent, colour, and reward systems;
5. independent guarded-defence replications that expand mechanism breadth rather than repeat the same chemical class.

## Revised stopping rule

Do not stop because descriptive class saturation has been reached.

A prediction can be considered empirically settled for this manuscript only when either:

1. its replication status and cross-system breadth are stable under additional targeted source-adjudicated searching, and compatible quantitative synthesis has been completed where capacity permits; or
2. the literature has been source-audited enough to demonstrate that the prediction is genuinely underidentified, with the exact missing design/effect-size cells documented.

The manuscript-level stopping decision is reached only when all U1-U8 predictions have an explicit status and further targeted searching does not materially alter those statuses.

## Inference boundaries

Always preserve:

```text
marginal route evidence != W_AD
same-system evidence != direct A x D
study count != prevalence
guarded defence example != universal complementarity
secondary-synthesis count != route-ledger N
zero direct joint-cost studies != kappa = 0
```
