# Narrow identification stop rule v1

The mechanism-first universality program has reached stable cross-system conclusions for U1-U6. Remaining evidence work is no longer open-ended literature expansion.

## U7 direct A x D

Keep open only for:

1. exact adjudication of Kessler et al. 2008 (`10.1126/science.1160072`), including recoverable genotype/day counts and intervention-specificity audit;
2. any newly found source that independently varies a validated floral attraction trait `A` and a separately validated flower-specific antagonist-reducing trait `D` on the same units and reports a shared reproductive/fitness outcome.

Do not reopen U7 for:

- pollinator x herbivore agent factorials;
- phenotypic selection only;
- reward x attraction designs where the second axis is not a validated D;
- one-compound dual function without independent A and D axes;
- correlated trait studies.
