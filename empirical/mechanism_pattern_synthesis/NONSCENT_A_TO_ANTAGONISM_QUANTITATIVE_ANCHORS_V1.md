# Non-scent A -> antagonism quantitative anchors v1

## Purpose

Strengthen U2 beyond floral scent by asking whether visually attractive floral traits are independently tracked by antagonists in quantitative or experimentally manipulated systems.

## 1. Dalechampia scandens — showy bract area

Primary source: Pérez-Barrales et al. 2013, *Oikos* 122:1411–1428, DOI `10.1111/j.1600-0706.2013.20780.x`.

The same continuous visual display axis is associated with both pollinator use and seed-predator use.

Source-reported translations for a +1 SD increase in bract area:

```text
patch pollinator visitation probability: 83.1% -> 94.4%
within-patch visitation:                  +7.6 percentage points
stigma pollen load:                       +49.9%
seed predation probability:               ~0.2% -> ~2.5%
```

For descriptive scale comparison only, the source-predicted probabilities imply approximate one-SD logit changes of:

```text
pollinator patch visitation: +1.232
seed predation:               +2.549
```

These are **not** uncertainty-bearing re-estimates because the covariance/model coefficient structure is retained in the source model and is not reconstructed from the rounded predicted probabilities.

Mechanism-facing result:

> a larger visual attraction display simultaneously increases mutualist use and antagonist seed-predator exposure in the same biological system.

This is a quantitative non-scent `A -> antagonism` anchor and a same-system `A -> pollination` / `A -> antagonism` replication. It is not direct `A x D` evidence because no focal defence trait is independently manipulated.

## 2. Hibiscus moscheutos — petal display size manipulation

Primary source: Kudoh & Whigham 1998, *Oecologia* 117:70–79, DOI `10.1007/s004420050633`.

The study experimentally reduced petal radius by 0%, 50%, or 100% and measured pollinator and pollen/seed-predator responses.

Source-supported pattern:

- two legitimate pollinator species ignored flowers with complete petal removal, establishing petals as a visual attraction cue;
- 50% petal reduction did not produce a corresponding large female-fitness effect relative to intact controls;
- adult *Althaeus hibisci* pollen predators occurred at higher density on flowers whose petals were not reduced;
- petal size did not correspondingly change later seed predation, so antagonist tracking is response-stage specific (adult pollen feeding rather than larval seed damage).

Exact uncertainty-bearing treatment coefficients are not reconstructed here because the publicly indexed abstract does not expose the full model table. This study is retained as an **experimental directional non-scent replication**, not a pooled effect.

## Cross-system interpretation

Together with existing visual/color systems (`Raphanus`, `Silene`, `Impatiens`), these studies make shared attraction tracking broader than an olfactory-special case.

The recurring higher-level pattern is:

```text
visual floral apparency can be exploited by both legitimate visitors and antagonists
```

but the antagonist response may occur at different stages (host location, pollen feeding, oviposition, seed predation), so outcome-stage mixing would obscure recurrence.

## U2 implication

U2 should be read as **cross-modality recurrence** rather than a scent-only signal result:

- scent: multiple quantitative/source-adjudicated systems;
- visual bract/display size: Dalechampia quantitative source-model translation;
- petal size: Hibiscus experimental directional replication;
- petal colour: Raphanus recurrent field/choice evidence;
- colour+scent recombinant axes: Silene.

## Boundaries

```text
A -> antagonism != W_AD
shared signal tracking != selection coefficient prevalence
rounded predicted probabilities != independent raw-data effect sizes
adult antagonist attraction != downstream seed-predation effect
same-system A routes != direct A x D
```
