# Silene latifolia 2014 floral-signal × fruit-predation audit v1

## Source

Page P, Favre A, Schiestl FP, Karrenberg S. **Do flower color and floral scent of Silene latifolia covary?** / associated *Silene latifolia* floral-trait–fruit-predation analysis in PLOS ONE 2014, DOI `10.1371/journal.pone.0098755`.

The primary PLOS article reports floral colour and scent traits together with fruit predation by the nursery-pollinating/seed-predating moth system.

## Pattern question

Do floral signal traits that belong to the attraction phenotype also predict antagonist attack in an independent moth nursery-pollination system?

## Source-verified Pattern

Fruit predation varied with several floral signal dimensions. The source reports associations involving petal colour saturation and individual scent compounds including linalool / lilac-aldehyde-related volatile variation.

These traits belong to the floral sensory phenotype used by nocturnal flower visitors. In *S. latifolia*, floral odour is a well-established cue for moth attraction and host finding; the 2014 study asks whether the same multidimensional phenotype also predicts predation.

Pattern state:

```text
A (floral colour / scent phenotype) -> antagonist fruit predation: trait-dependent association
```

The study is not converted into one synthetic A coefficient because colour and individual volatile dimensions are not exchangeable measures of a single scale.

## Nursery-pollinator boundary

The relevant *Hadena* moth system has an unusual dual interaction: adult moths can pollinate while larvae consume developing seeds. This does not make every floral signal coefficient simultaneously an `A -> pollination` estimate. The 2014 analysis is promoted only for the antagonist route that it directly quantifies.

## Theory-facing mapping

Admitted:

```text
floral sensory/display traits can predict antagonist attack outside the current Cucurbita/Dalechampia/Raphanus systems
A -> antagonism recurrence spans colour and scent components
floral signal effects are multidimensional rather than reducible to one universal attraction axis
```

Not admitted:

```text
fruit predation coefficient = W_AD
Hadena adult pollination = same-study A -> pollination estimate
all scent compounds are equivalent A units
nursery pollination = direct A x D
```

## Independence value

This adds a distinct plant lineage and antagonist life history to the A-side route architecture. It is kept independent from the *Silene stellata* context program because the species, study, and focal inference differ.
