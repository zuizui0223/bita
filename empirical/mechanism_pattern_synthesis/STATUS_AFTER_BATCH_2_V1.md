# Mechanism-pattern synthesis status after execution batch 2

## Bottom line

The project has moved beyond protocol design. It now contains source-adjudicated same-system mechanism records, the first direct observational `A x D` interaction cluster, and a quantitative `A -> antagonism` anchor recovered from an exact public-data linkage.

The manuscript remains frozen because the search and quantitative synthesis gates are not yet saturated.

## Current evidence inventory

### Direct interaction layer

```text
verified Tier-1 observational A x D clusters: 1
verified Tier-1 experimental A x D clusters:  0
```

The single verified cluster is Soper Gorden & Adler (2018), `Impatiens capensis`.

Two reproductive-component interactions are estimable on the same individual-plant panel:

```text
CH fruits per plant per day: beta_AxD = -0.0820, SE 0.0548, n=170
seeds per CH fruit:          beta_AxD = +0.1040, SE 0.1043, n=85
```

Both confidence intervals include zero and the point estimates have opposite signs. The direct interaction sign is therefore unresolved, not negative or positive.

### Quantitative A -> antagonism layer

A reproducible public-data effect from Gross, Sun & Schiestl (2016), `Gymnadenia odoratissima`, is now registered:

```text
outcome: eaten flowers / total flowers
n = 1162 linked marked plants
beta = +0.56814 per 1 SD log1p total floral scent
SE = 0.26854
95% CI = [0.04181, 1.09446]
p = 0.03437
```

This is a strong quantitative anchor for attraction tracking by floral antagonists, while remaining a same-day observational association rather than a causal scent manipulation.

## New scientific information produced by the work

The current evidence already argues against the empirical shortcut

```text
D -> pollinator use = one universal negative coefficient.
```

The same defence/filter trait can instead show:

- no detectable legitimate-pollinator cost while reducing robbery (`Ipomopsis`);
- pollinator cost only at high expression (`Polemonium`);
- time-dependent deterrence (`Asclepias`);
- opposite signs for visit number versus residence/consumption (`Nicotiana`);
- an imprecise negative pollinator-use association in a linked individual panel (`Impatiens`).

This is precisely why mechanism recurrence and sign-switch rules are the primary synthesis targets rather than a cross-system grand mean.
