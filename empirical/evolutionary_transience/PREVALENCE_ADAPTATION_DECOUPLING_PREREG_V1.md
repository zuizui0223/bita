# Prevalence–adaptation decoupling test v1

Status: **FROZEN BEFORE CROSS-DATASET OUTCOME OPENING**

Frozen on: 2026-10-07
Branch: `analysis/ecological-stability-evolutionary-transience-v1`

## Motivation

The active BITA Letter shows that a high conditional share of nectar robbery can arise
because legitimate interactions disappear faster, even when the absolute robbery route
does not increase. That decomposition creates an evolutionary prediction that is not
contained in the current Letter.

Selection for a bypass-specialized phenotype should track the absolute fitness/resource
return generated by bypass use, not the conditional fraction of surviving interactions
that happen to be bypasses. Therefore a high robbery share can be evolutionarily weak
when it is denominator-driven.

The literature already establishes:
- morphology/access mismatch -> greater conditional robbery in hummingbirds;
- repeated evolution of clinging-associated hummingbird morphology;
- rare examples of morphology specialized for primary nectar robbery in other taxa.

This test does **not** claim those facts as new. The target is whether conditional
robbery prevalence and zero-inclusive absolute robbery participation carry different
evolutionary information.

## Hypothesis

### H2 — prevalence–adaptation decoupling

Across hummingbird species in the Ecuador EPHI network, a bypass-associated morphology
should align more strongly with **zero-inclusive absolute robbery participation** than
with **robbery share conditional on an observed feeding interaction**.

Conceptually:

```text
robbery_share = robbery / (robbery + legitimate)

can rise when:
robbery stays constant
legitimate falls

but selection for robber-specific performance should require an absolute payoff
from the robbery route.
```

Hence:

```text
morphological assimilation ~ absolute robbery gain
                         != conditional robbery prevalence
```

## Frozen data sources

### Ecological route use
Aubert/EPHI Ecuador public interaction and camera tables
(Zenodo 10.5281/zenodo.14185547; Dryad 10.5061/dryad.rn8pk0pqx).

### Morphology / independent behaviour classification
Colwell et al. 2023 Supplemental Spreadsheet S1
(Harvard Dataverse doi:10.7910/DVN/THDJCI).

Only Trochilidae present in both datasets are used. Diglossa flowerpiercers are excluded
from this cross-dataset test because they are not hummingbirds and are absent from the
Colwell morphology frame.

## Frozen ecological estimands

Use the same metadata-informed route coding as the active BITA participation analysis:

- `piercing=yes` = robbery;
- `piercing=no` = legitimate;
- blank/NA piercing = legitimate under the source metadata-informed primary rule;
- explicit `feeding_activity=no_feeding` excluded;
- ambiguous nonbinary route states excluded.

Opportunity denominator:
- unique clean camera waypoint;
- crossed with a hummingbird species observed elsewhere at the same site during one
  of that waypoint's valid clean-camera date intervals;
- exposure effort = summed positive camera sampling hours for the waypoint.

For each joined hummingbird species compute:

1. **conditional robbery share**
   `R_share = N_rob / (N_rob + N_legit)`;

2. **absolute robbery event rate**
   `R_abs = N_rob / available_camera_hours`;

3. **absolute legitimate event rate**
   `L_abs = N_legit / available_camera_hours`;

4. **zero-inclusive robbery participation**
   fraction of eligible waypoint opportunities with >=1 robbery record.

Primary ecological contrast is `R_abs` versus `R_share`.
The other two are diagnostics and cannot replace it after results are seen.

## Frozen morphology estimands

From Colwell Supplemental Spreadsheet S1 use the source-computed
body-size/elevation/phylogeny filtered values:

- `Both Sexes Triple-filtered Hallux Claw`;
- `Both Sexes Triple-filtered Exposed Culmen`.

Define the bypass-morphology index before outcome opening:

```text
M_bypass = z(triple_filtered_hallux_claw)
           - z(triple_filtered_exposed_culmen)
```

Higher values represent the short-bill / long-hallux direction associated by Colwell
et al. with clinging/unorthodox feeding.

Primary behavioural state is Colwell's published **clinger** classification, reconstructed
only from the four frozen feeding-style indicator columns that the source study treats
as clinging-required behaviours.

## Primary tests

Among species with both EPHI estimands and Colwell data:

### T1 — continuous morphology

Compute Spearman correlations:

```text
rho_abs   = cor_rank(M_bypass, log1p(R_abs))
rho_share = cor_rank(M_bypass, R_share)
```

Primary prediction:

```text
rho_abs > rho_share
```

Assess the paired difference
`Delta_rho = rho_abs - rho_share`
with a species bootstrap. Report the full interval; no dichotomous claim if the
interval spans zero.

### T2 — independent source behaviour classification

Compare clingers versus presumed non-clingers for `R_abs` and `R_share`.

Primary prediction:

```text
standardized clinger contrast for R_abs
>
standardized clinger contrast for R_share
```

This is corroborative because clinger state is behavioural rather than morphology alone.

## Inclusion / sensitivity rules

Primary analysis:
- all joined Trochilidae with >0 eligible camera exposure hours and >=1 resolved
  feeding interaction;
- no minimum interaction-count threshold chosen from the observed outcome.

Frozen sensitivities:
1. require >=10 resolved feeding events;
2. require >=20 resolved feeding events;
3. explicit yes/no piercing only (do not recode blank/NA);
4. exclude species represented by only one eligible waypoint;
5. analyze the two component morphology variables separately.

If any threshold changes the conclusion, report the instability rather than selecting
the favorable threshold.

## Claim rule

Promote H2 only if the absolute-route metric is more strongly aligned with the
bypass phenotype than conditional robbery share in both the continuous morphology
test and the clinger-state contrast, with the direction retained in the main
sensitivities.

Allowed interpretation if supported:

> The prevalence of an interaction mode need not measure the selective opportunity
> for specializing on that mode. When prevalence rises through loss of the alternative
> route, ecological rerouting can be strong without a corresponding increase in the
> absolute payoff available to drive morphological assimilation.

Not allowed:
- causal proof that robbery created the morphology;
- universal claim across nectar robbers;
- treating EPHI species as independent evolutionary origins;
- replacing the source phylogenetic analysis;
- claiming that conditional prevalence is never evolutionarily informative.

## Link to the transience hypothesis

If H2 is supported, it provides a mechanistic explanation for why bypass behaviour can
be ecologically conspicuous yet macroevolutionarily transient: denominator-driven
prevalence can make cheating look common without increasing the absolute route return
that would favor stable morphological specialization.

If H2 fails, the ecological-stability/evolutionary-transience test remains logically
separate and must not be rescued by post-hoc reinterpretation.
