# Matched-D focused search stopping rule v1

## Purpose

Define a bounded stopping point for additional matched floral-defence retrieval so the project does not drift into indefinite literature harvesting.

## Target

Only studies that can materially change one of the current high-value cells:

~~~text
SEPARATED + chemical + direction-supported pollinator state
OVERLAPPED + physical + direction-supported pollinator state
physical D + direct same-study pollinator outcome
prospectively classifiable new matched-D system
~~~

Frozen admission rule remains:

~~~text
same focal flower-associated D
+ independently defensible antagonist-reducing role
+ antagonist response under that D
+ legitimate pollinator / pollination-function response under the same D
+ study identity and dependence controlled
~~~

## Bounded targeted search completed

Search families included combinations of:

- physical floral defence / slippery / sticky / hair / bract / corolla barrier;
- nectar robber / thief / florivore / seed predator / ant;
- pollinator / pollination / visitation / pollen transfer;
- floral chemistry / nectar chemistry / same-trait antagonist and pollinator response;
- recent 2020–2026 studies and backward/forward source chasing around admitted systems.

## High-information hits

### Already admitted

- *Caryopteris divaricata* — geometry / nectar-robbing system; systematic expansion.
- *Thunia alba* — bract-removal experiment; strict separated physical system.
- *Pedicularis rex* — water-filled bract manipulation; physical null-compatible pollinator state.
- *Phlox paniculata* — chemical ant-repellence system; systematic expansion.

### Informative but still outside strict admission

- Takeda et al. 2021: slippery perianth directly excludes ants and ant presence disrupts hornet pollinators, but the slippery D itself is not directly manipulated against pollinator response.
- Chautá et al. 2022: floral stickiness directly reduces florivory, but direct pollinator cost remains unresolved.
- Carlson & Harms 2007: water calyx directly reduces floral herbivory; same-D pollinator response is not experimentally closed.
- Tagawa 2018: petal hairs directly restrict nectar-thieving ants; same-D pollinator response is not measured.
- *Tirpitzia sinensis* 2023: robbing, floral morphology/chemistry and reproductive effects are studied, but the candidate defensive traits are not manipulated as a common D against antagonist and pollinator channels.
- recent *Asclepias syriaca* studies connect defensive traits, herbivory and pollination, but do not supply the frozen same-D D-to-antagonism plus D-to-pollination contrast required here.
- Sakhalkar et al. 2023 supplies the independent community-scale route-association layer, not a same-D experiment.

## Stopping decision

~~~text
new strict matched-D systems in latest targeted expansion: 0
eligibility rule relaxed:                              NO
broad undirected literature search:                    STOP
future retrieval mode:                                 CONDITION-TRIGGERED
~~~

Condition-triggered retrieval means the search is reopened only when:

1. a new paper explicitly manipulates a floral defence/access trait and reports both antagonist and legitimate-pollinator responses;
2. a public dataset becomes available for a currently unresolved high-value system;
3. a specific missing Stage-2 cell is named and a targeted query is justified.

## Scientific implication

The present small strict Stage-2 sample is not simply a consequence of failing to search broadly enough. The source literature often measures either antagonist defence or pollination consequences, but not both under the same focal D.

This measurement structure is itself an empirical result and motivates the physical-D pollinator-follow-up experiment specified in `PHYSICAL_D_POLLINATOR_GAP_AUDIT_V1.md`.

## Claim boundary

This is a bounded stopping rule for the current project, not a claim that every relevant paper in the global literature has been exhaustively enumerated.
