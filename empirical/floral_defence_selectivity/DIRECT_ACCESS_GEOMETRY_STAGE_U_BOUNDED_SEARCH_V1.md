## Why formal recurrence remains closed

Two independent blockers remain.

### 1. Historical source provenance

The Leal et al. (2025) historical anchor contains 56 distinct `study` labels,
but two labels combine rows that cannot all originate from their named sources:

- `Varma&Sinu2019`;
- `Zhangetal2009a`.

The source-level denominator therefore remains unresolved.

### 2. Exhaustive bibliographic update frame

The generic web search used here is bounded and documented but is not an
exhaustive, exportable bibliographic database result set. The environment did
not provide direct access to a stable OpenAlex API result set for freezing the
full update denominator.

A formal directional recurrence statistic may open only after a finite,
deduplicated bibliographic update frame is exported and all records are screened
outcome-independently.
