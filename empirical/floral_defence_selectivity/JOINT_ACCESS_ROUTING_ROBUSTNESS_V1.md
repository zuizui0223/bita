# Joint access-routing sparse-pair robustness v1

## Question

Does the equal-network Letter result depend on Aubert/EPHI bird × plant × site units represented by only one resolved interaction?

Sakhalkar plant-species units are unchanged. Aubert/EPHI pair-sites are filtered at minimum interaction counts of 1, 2, and 5, and the same site-adjusted rank effect and equal-network joint test are recomputed.

## Results

~~~text
minimum >= 1 interaction
  Aubert n = 1,378
  Aubert site-adjusted rho = 0.3505
  joint rho = 0.3487
  joint permutation p = 0.0001

minimum >= 2 interactions
  Aubert n = 1,059
  Aubert site-adjusted rho = 0.4040
  joint rho = 0.3757
  joint permutation p = 0.0001

minimum >= 5 interactions
  Aubert n = 702
  Aubert site-adjusted rho = 0.4229
  joint rho = 0.3855
  joint permutation p = 0.0001
~~~

All three thresholds retain:

~~~text
network direction concordance = 2 / 2 positive
Aubert within-site permutation p = 0.0001
joint permutation p = 0.0001
~~~

## Interpretation

The joint access-routing result is not generated by the many Aubert/EPHI pair-site units represented by a single interaction.

Instead, the standardized association is stable and becomes modestly stronger descriptively when sparse pair-sites are removed.

The Letter can therefore state:

> **The cross-network routing effect persisted after requiring at least five resolved interactions per Aubert/EPHI pair-site unit (joint rho = 0.385, p = 0.0001).**

## Claim boundary

This robustness analysis does not change the observational nature of either network.

It does not justify:

- a causal effect of floral geometry;
- a common raw-scale effect size;
- a random-effects meta-analysis interpretation;
- treating pair-site rows as independent networks.

Networks remain equally weighted.
