# Matched-D systematic search protocol v1

## Purpose

Expand the floral-defence selectivity corpus without replacing or reinterpreting prior BITA evidence.

The target is a **same-system matched defence contrast**:

> one flower-associated defence/access trait or manipulation evaluated against an antagonist response and a legitimate-pollinator or pollination-function response in the same biological system.

This protocol is separate from the pre-existing 2020–2026 hold-out protocol. The hold-out protocol remains frozen and is scored separately. This all-years search is an expansion/completeness layer, not prospective validation of the rule.

## Fixed concept families

1. `floral defence pollinator antagonist manipulation flower barrier`
2. `floral chemical defence pollinator herbivore nectar manipulation`
3. `floral physical defence pollinator florivore barrier manipulation`
4. `nectar secondary metabolite pollinator antagonist experiment`
5. `flower trait pollinator herbivore access manipulation`
6. `floral trichome pollinator herbivore experiment`
7. `sticky flower pollinator florivore experiment`
8. `floral barrier pollinator nectar robber experiment`

Equivalent syntax may be used by a search engine, but the biological concepts are not changed after outcome inspection.

## Eligibility

Include only if all are true:

1. primary empirical study;
2. flower-associated D candidate is operationally defined;
3. antagonist response is measured;
4. legitimate-pollinator response, pollination function, or a pollinator-dependent reproductive response is measured in the same biological system;
5. D architecture can be coded without using the focal pollinator outcome;
6. source provenance is recoverable.

A study can be admitted with `UNCLEAR` architecture, but it cannot be used to support the domain-separation predictor until architecture is independently classifiable.

## Exclusions

- vegetative defence only;
- pollinator-only nectar chemistry studies with no antagonist response;
- antagonist-only floral defence studies with no direct pollinator/pollination outcome;
- inferred pollinator costs not measured in the source;
- review/meta-analysis as the matched-system unit;
- duplicated biological systems already represented by the same experiment.

## Cohorts

- `derivation`: evidence used historically to formulate or refine the domain rule;
- `holdout`: systems admitted under the frozen 2020–2026 hold-out protocol;
- `systematic_expansion`: new all-years matched-D systems found after the current refocus.

These cohorts are never pooled without a cohort indicator/sensitivity analysis.

## Search saturation

Stop only when:

1. all fixed concept families have been searched;
2. admitted new systems receive backward/forward citation checks;
3. two consecutive citation-expansion rounds add no eligible independent system;
4. every retained candidate has an explicit include/exclude/unresolved disposition.

Search saturation is a literature-completeness statement, not natural prevalence.
