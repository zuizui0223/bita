# Direct access-geometry → nectar-robbery evidence contract v1

## Purpose

The primary access-routing Letter has a frozen standardized network test with
`k = 2` independent networks. This file defines a separate supporting evidence
layer for direct empirical tests of the narrower biological relation:

~~~text
greater difficulty of legitimate floral access
        ->
greater probability / frequency / intensity of bypass or nectar robbery
~~~

This corpus is **not** a way to manufacture additional network replicates. A study
enters the network-level joint statistic only if it separately passes
`THIRD_ACCESS_ROUTING_NETWORK_PREREG_V1.md`.

## Inclusion rule

A study is eligible for this direct-evidence corpus when all of the following are
recoverable from the primary paper or its public data:

1. an empirical field, common-garden, or behavioral experiment;
2. a floral geometry or visitor–flower access variable measured independently of
   the robbery outcome (for example corolla/tube length, aperture, or a direct
   visitor–flower mismatch);
3. a response that directly records bypass/robbery route use, robbery probability,
   robbery frequency, robbery intensity, or legitimate-versus-illegitimate use;
4. a quantitative comparison or model from which the direction of the
   geometry–robbery relation can be coded;
5. enough provenance to distinguish the biological study from duplicate reports of
   the same data.

## Exclusion rule

Do not count:

- studies that discuss access geometry only mechanistically without testing it;
- studies with total visitation, pollen transport, fitness, or nectar removal as the
  only response and no route-resolved robbery outcome;
- studies in which the focal access predictor was selected from the robbery outcome;
- re-analyses of the same biological observations as separate independent systems;
- the two standardized Letter networks as additional direct-study replicates in any
  formal count unless explicitly labelled as overlap.

## Direction coding

~~~text
POSITIVE = greater access constraint / longer or less accessible flowers -> more robbery
NULL     = tested access variable has no supported association with robbery
OPPOSITE = greater access constraint -> less robbery
MIXED    = direction differs across predeclared strata or access dimensions
~~~

A null or opposite result remains in the corpus.

## Independence unit

The descriptive unit is the **study program / biological dataset**, not every
coefficient, population, species, or year. Multiple tests from one program are retained
inside one row as details.

## Search status and inference ceiling

Version 1 is a **bounded discovery corpus**, seeded from the access-routing literature
already cited by the Letter and targeted searches for direct morphology–robbery tests
through 2026-09-24. It is not yet a systematic-review sampling frame.

Therefore:

- report the studies and their directions;
- use the corpus to show that the biological relation has been directly tested beyond
  the two standardized networks;
- do **not** estimate prevalence;
- do **not** run a sign test or meta-analysis on the discovery corpus;
- do **not** add these rows to `k`;
- do **not** describe them as independent standardized network replications.

A formal recurrence statistic requires a separately frozen systematic search and
deduplication protocol.

## Relation to the primary Letter

The allowed wording is:

> Only two datasets currently satisfy the standardized cross-network estimand, but
> direct experimental, population-level and community-level studies have tested the
> same access-geometry prediction in additional systems, including both supporting
> and null results.

The corpus strengthens mechanistic recurrence while preserving the current
`JOINT_NETWORK_K = 2` claim ceiling.
