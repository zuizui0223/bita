## Diagnostic question

The prior robbery model M2, with camera-waypoint and bird-species-by-site fixed
effects, failed the fixed 10,000-iteration IPF convergence test. Its category
coefficients stabilized numerically, but the nuisance margins converged extremely slowly.

Does the exact observed row/column/category count vector lie in the
**relative interior** of the cone generated by all supported opportunity-cell
design vectors? A finite maximum-likelihood solution of the Poisson loglinear
model requires an interior point. If its sufficient-statistic margins can only
be matched with some fitted cell intensities equal to zero, no finite joint
Poisson-MLE parameter vector can match the observed sufficient statistics.

## Linear-program calculation (purely diagnostic)

For every supported opportunity cell e, introduce a hypothetical fitted
expectation `x_e` and shared minimum positive lower bound `epsilon`.

Maximize `epsilon`, subject to:

```text
  x_e >= epsilon >= 0 for every supported e
  sum_{e in waypoint w} x_e = observed robbery/legitimate waypoint total(w)
  sum_{e in bird group b} x_e = observed robbery/legitimate bird-group total(b)
  if categories included:
    sum_{e in mismatch category k} x_e = observed route-category total(k)
```

No ecological rate coefficient is fitted by this LP. It is only a
necessary/sufficient interior-feasibility check on the Poisson
exponential-family sufficient-statistic support. A strictly positive solution
exists iff the maximum epsilon is >0. A numerical optimum of zero indicates a
boundary / separation configuration.

SciPy HiGHS returned success in all locally run models:

|---|---|---|---:|---:|
| robbery | waypoint + bird | yes | 3,371 | 0.01075269 |
| robbery | waypoint + bird×site | yes | 2,563 | **0** |
| robbery | waypoint + bird×site | no | 2,563 | **0** |
| legitimate | waypoint + bird | yes | 15,377 | 0.11111111 |
| legitimate | waypoint + bird×site | yes | 15,352 | 0.07692308 |
| legitimate | waypoint + bird×site | no | 15,352 | 0.07692308 |

The exact observed row/column margins were satisfied in the solved LPs
(maximum absolute equality residual reported for robbery M2 = zero at
solver precision). The same boundary appears **even after removing the
three mismatch category constraints**.

### Interpretation of the obstruction

The problem is attributable to the combination of **sparse robbery
counts and the bird×site × waypoint opportunity support**. It is not a
threshold-location artifact and not merely a too-strict IPF tolerance.
A finite vector of all Poisson nuisance fixed-effect coefficients cannot
satisfy these margins with strictly positive fitted intensity for every
supported cell. Boundary separation explains why IPF can drive some
nuisance effects toward limiting values indefinitely.

This is a statement about the **joint** finite Poisson MLE, not a formal proof
that the mismatch coefficient has no identifiable finite limiting contrast
in an extended-likelihood model. A different estimator could in principle
return a finite limit, but using one now as confirmatory evidence would violate
the analysis's outcome-independent criterion and would require a separate
methods audit.

### Explicit constrained-cell witness

The category-free robbery M2 transportation-margin LP was also separately
re-solved after setting the objective to maximize the expected value of one
anonymous supported opportunity, `waypoint_1297 × bird_041@@site_07`
(plant `plant_139`, observed robbery count 0). Under the **unchanged**
observed waypoint and bird×site margins, its maximum feasible value was
**zero** at the HiGHS optimum. This exhibits a supported opportunity
that is forced to have zero expectation when margins are matched,
so a strictly positive finite-parameter Poisson fit cannot reproduce
the data's sufficient statistics.

The witness is a mathematical **support/margin** statement, not a new
test of the mismatch predictor; its observation was never used to
change the model's covariates or inclusion filters.
