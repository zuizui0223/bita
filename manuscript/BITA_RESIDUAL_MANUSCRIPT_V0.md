# Trait interaction is not ecological mechanism

## Abstract

Multi-trait fitness interactions are often interpreted mechanistically, but an interaction term alone does not identify the ecological route that generated it. This problem is especially acute after trait differentiation, when multiple axes can jointly affect pollinators, antagonists, direct performance, and residual channels. We develop an identification ladder that separates interaction detection from ecological mechanism identification. The framework progresses from total interaction to identified sets, partial identification, selective crossed interventions, separability diagnostics, and independent remaining-channel assays. A synthesis of source-adjudicated biological systems is used to map where constituent biology is recurrent but causal mechanism identification remains incomplete. The resulting framework treats fragmented identification as a property to diagnose, not a reason to overinterpret interaction coefficients.

## 1. The identification problem

For two traits `A` and `D`, the total fitness interaction is

```text
Delta_AD W = W11-W10-W01+W00.
```

A nonzero value establishes nonadditivity on the chosen fitness scale. It does not identify which ecological pathway generated that nonadditivity.

Possible pathways include changes in mutualist attraction, antagonist deterrence, direct biomechanical performance, resource allocation, or interactions among these channels.

## 2. Inference ladder

We separate six levels:

```text
interaction detection
-> identified set
-> partial identification
-> selective A x D x ecological-state intervention
-> separability diagnostic
-> independent remaining-channel assay.
```

Each level narrows the set of compatible mechanisms without pretending that a lower level implies a higher one.

## 3. Selective intervention design

A focal floral implementation crosses

```text
A x D x antagonist x pollinator
```

on one common reproductive fitness scale. The purpose is not merely to estimate a four-way interaction, but to ask whether the contribution attributed to one ecological route disappears or changes predictably when that route is selectively removed.

## 4. Structural differentiation is not functional independence

Distinct trait axes can remain genetically, developmentally, mechanically, or ecologically coupled. Therefore

```text
structural separation
!= functional independence.
```

Likewise,

```text
positive A x D interaction
!= trait differentiation
!= historical splitting.
```

The framework retains residual coupling as an empirical possibility rather than treating it as model failure.

## 5. Comparative evidence

The retained evidence base contains source-adjudicated route records grouped into independent biological clusters, including a high-information frontier where multiple routes have been experimentally distinguished. The synthesis is used to characterize identification depth and recurring constituent biology, not to estimate the prevalence of differentiated architecture.

## 6. Discussion

The main contribution is an identification principle: mechanistic interpretation requires selective information about ecological channels, not only a statistically significant interaction among traits. Interaction coefficients are therefore entry points into mechanism analysis rather than mechanistic conclusions.
