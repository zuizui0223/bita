# Figure captions — BITA mechanism-identification paper

The existing rendered figure files were built for the older integrated architecture-plus-mechanism manuscript and must be regenerated. These captions define the new five-figure Main sequence.

## Figure 1. A trait interaction is an outcome estimand, not a mechanism allocation.

**A**, Four-cell factorial for focal traits `A` and `D`, with `A0 = W10-W00`, `A1 = W11-W01`, and `Delta_AD W = A1-A0`. **B**, Nested outcome claims: Level 1 positive interaction relief requires `Delta_AD W > 0`; Level 2 functional constraint release additionally requires `A0 <= 0 < A1`; Level 3 strict reversal requires `A0 < 0 < A1`. **C**, Equal positive values of `Delta_AD W` can arise from very different channel allocations. The figure therefore separates the measured interaction from the mechanism question before any decomposition is introduced.

## Figure 2. The total interaction defines an identified set of compatible ecological mechanisms.

Write `Delta_AD W = rho_delta - iota_delta - kappa_delta`, where `rho_delta` is antagonist relief, `iota_delta` is pollinator interference, and `kappa_delta` is a remaining direct/allocation channel that requires independent biological justification. For a measured total interaction `delta`, compatible mechanisms lie on `I(delta) = {(rho,iota,kappa): rho-iota-kappa=delta}`. **A**, The unrestrained identified set. **B**, An explicit restriction such as `kappa_delta >= 0` cuts the set and yields the partial-identification bound `rho_delta-iota_delta >= Delta_AD W`. **C**, A bounded independent channel assay or selective consumer measurement shrinks the set further. Precision in the total interaction alone does not collapse the set to a point.

## Figure 3. Crossed consumer intervention promotes a trait interaction toward mechanism identification.

A selective `A × D × antagonist × pollinator` experiment crosses the same trait contrasts with consumer-access states. **A**, Antagonist exclusion identifies the attraction-by-defence interaction in antagonist-mediated loss when the intervention is selective. **B**, Pollinator access identifies the pollinator-dependent interaction, but pollinator-independent reproduction must be measured or independently justified rather than assumed to be zero. **C**, The `A × D × antagonist × pollinator` four-way interaction is the separability diagnostic: a non-zero term shows that the proposed consumer-channel allocation itself depends on the alternate consumer state. **D**, After the biotic channels are identified, the remaining joint channel is compared with an independent assay; a residual by subtraction is not automatically a biological cost.

## Figure 4. Existing evidence forms a fragmented identification frontier rather than a complete mechanism design.

The source-adjudicated synthesis contains 56 directional route records from 25 independent biological clusters and shows recurrence of all four constituent marginal pathway families. The stricter high-information audit contains 17 systems that occupy complementary experimental faces. Trait-factorial anchors, consumer-factorial anchors, selective defence manipulations, attraction-by-consumer bridges, and public-data context-modification analyses each constrain different dimensions of the target design. No screened system closes the full trait factorial, selective crossed consumer intervention, baseline/separability gates, and independent remaining-channel assay. Counts describe evidence capacity and design coverage, not prevalence.

## Figure 5. The BITA promotion ladder and its boundary with SCH and SLK.

The active BITA inference sequence is `interaction detection -> identified set -> partial identification -> selective crossed intervention -> separability diagnostic -> independent remaining-channel assay -> mechanism-resolved interpretation`. SCH addresses the upstream promotion `multifunctionality != identified functional conflict`; SLK transports an identified conflict budget through `L -> R -> Phi -> accessibility -> invasion -> fixation -> occupancy`; BITA begins once multiple trait axes are observed and asks `trait interaction != mechanism`. Architecture-value derivations are shown only as programme context and are not active BITA novelty claims.
