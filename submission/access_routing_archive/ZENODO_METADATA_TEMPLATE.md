# Zenodo metadata staging — access-routing Letter archive

**Upload title:** Data and code for “Access constraints predict interaction routing across bird and insect visitor networks”

**Upload type:** Dataset / software companion package

**Creator(s):** AUTHOR-CONTROLLED — use final manuscript author list and ORCIDs.

**Description:**

Analysis-ready data tables, metadata, code and frozen derived outputs supporting the Ecology Letters Letter “Access constraints predict interaction routing across bird and insect visitor networks.” The package reproduces the all-Ecuador bird–flower routing analysis after metadata-informed recoding of unspecified piercing records as legitimate/non-robbing interactions, with primary inference at 259 plant species reconstructed from 2,265 anonymous bird × plant × site aggregation units. It additionally reproduces the preregistered zero-inclusive participation decomposition from an anonymous clean-waypoint × locally available bird opportunity table, including the frozen barrier/access resolved feeding-visit rate ratio (1.7717; 95% plant-jackknife CI 1.1050–2.8405) and participation-increase-plus-routing classification. The same anonymous clusters reproduce paired and continuous within-bird behavioral checks (36 and 28 bird species, respectively). It also reproduces the independent 57-species Afrotropical insect corroboration, the equal-network plant-species joint routing test (rho_J = 0.4282), and the post hoc mechanism audit of opposite/mixed formal-frame boundary cases. Anonymous waypoint, plant- and bird-species identifiers preserve fixed-effect and dependence checks without redistributing source taxon labels. Underlying source data are publicly archived by their original authors at Zenodo DOI 10.5281/zenodo.8398202 and Zenodo DOI 10.5281/zenodo.14185547.
