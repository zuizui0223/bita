# Zenodo metadata staging — access-routing Letter archive

**Upload title:** Data and code for “Access constraints predict interaction routing across bird and insect visitor networks”

**Upload type:** Dataset / software companion package

**Creator(s):** AUTHOR-CONTROLLED — use final manuscript author list and ORCIDs.

**Description:**

Analysis-ready data tables, metadata, code and retained derived outputs supporting the Ecology Letters Letter “Access constraints predict interaction routing across bird and insect visitor networks.” The package reproduces the all-Ecuador bird–flower routing analysis after metadata-informed recoding of unspecified piercing records as legitimate/non-robbing interactions, with primary inference at 259 plant species reconstructed from 2,265 anonymous bird × plant × site aggregation units. It reproduces the preregistered zero-inclusive participation result under the source-defined tube>culmen barrier (pooled resolved-feeding RR 1.7717, 95% CI 1.1050–2.8405) and the post-open route split (legitimate/non-robbing RR 1.8826, 1.1112–3.1896; robbery-only RR 0.4627, 0.1465–1.4608). Because hummingbird culmen length is not functional reach, the archive additionally reproduces the post-open Trochilidae-only reach sensitivity from anonymous `bird_group` labels: under a published one-third tongue-extension correction, pooled RR is 0.435 and legitimate RR 0.354; under the literature-anchored 80% correction, pooled RR is 0.229 and legitimate RR 0.154, while robbery-only counts remain unresolved. The archived plant-level table and code also reproduce the preregistered routing-threshold analysis and the 585/999 upper-boundary bootstrap audit. The same anonymous clusters reproduce within-bird routing checks, the independent 57-species Afrotropical insect corroboration, the equal-network joint routing test (rho_J = 0.4282), and the formal-frame boundary audit. Source taxon names are omitted; only the coarse hummingbird/flowerpiercer grouping is retained for the reach sensitivity. Underlying source data remain publicly archived at Zenodo DOI 10.5281/zenodo.8398202 and Zenodo DOI 10.5281/zenodo.14185547.
