# Zenodo metadata staging — access-routing Letter archive

**Upload title:** Data and code for “Higher nectar robbery prevalence under access mismatch need not reflect higher robbery rates”

**Upload type:** Dataset / software companion package

**Creator(s):** AUTHOR-CONTROLLED — use final manuscript author list and ORCIDs.

**Description:**

Analysis-ready data tables, metadata, code and frozen derived outputs supporting the Ecology Letters Letter “Higher nectar robbery prevalence under access mismatch need not reflect higher robbery rates.” The package reproduces the all-Ecuador bird–flower routing analysis after metadata-informed recoding of unspecified piercing records as legitimate/non-robbing interactions, with primary inference at 259 plant species reconstructed from 2,265 anonymous bird × plant × site aggregation units. It additionally reproduces the preregistered zero-inclusive participation decomposition from an anonymous clean-waypoint × locally available bird opportunity table, including the frozen barrier/access resolved feeding-visit rate ratio (1.7717; 95% plant-jackknife CI 1.1050–2.8405) and participation-increase-plus-routing classification. Route-specific columns in the same anonymous opportunity table reproduce the explicitly post-open decomposition (legitimate/non-robbing RR 1.8826, 95% CI 1.1112–3.1896; robbery-only RR 0.4627, 95% CI 0.1465–1.4608). The V5 table also retains an anonymous hummingbird/flowerpiercer group label, allowing the post-open physiological-reach sensitivity to be reproduced without source species names. The preregistered culmen-only definition yields a positive legitimate RR (1.8826), whereas three explicitly post-open hummingbird-only tongue-reach scenarios (4/3, 1.8, 2.0× culmen) consistently yield legitimate RR values below 1 with 95% intervals excluding 1 (0.3537, 0.1537, 0.1004). Corresponding robbery RRs (0.8512, 0.8164, 1.3929) all have 95% intervals including 1; their directions remain unresolved. Descriptive ratios across corrected reach scenarios range 2.406–13.876; at the 4/3 multiplier the ratio interval includes 1. At 1.8×, the descriptive ratio of their separately fitted rate ratios is 5.311 (1.923–14.672). These jackknife intervals are conditional on chosen multipliers, which are not measured species-specific reach values for all 49 hummingbird species. Route-specific fixed-effect fits retain different positive-margin opportunity supports, so this is not a common-risk-set substitution effect or a decomposition of the plant-level conditional robbery association. The archived plant-level table and code also reproduce the preregistered routing-threshold analysis and the post-open audit in which 585/999 bootstrap midpoint fits landed at the upper search boundary. The same anonymous clusters reproduce paired and continuous within-bird-species route-composition checks (36 and 28 bird species, respectively; individual birds were not tracked). It also reproduces the independent 57-species Afrotropical insect corroboration, the equal-network plant-species joint routing test (rho_J = 0.4282), and the post hoc mechanism audit of opposite/mixed formal-frame boundary cases. Anonymous waypoint, plant- and bird-species identifiers preserve fixed-effect and dependence checks without redistributing source taxon labels. Underlying source data are publicly archived by their original authors at Zenodo DOI 10.5281/zenodo.8398202 and Zenodo DOI 10.5281/zenodo.14185547.
