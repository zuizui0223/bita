# Zenodo metadata staging — access-routing Letter archive

**Upload title:** Data and code for “Access constraints reroute floral exploitation across bird and insect visitor networks”

**Upload type:** Dataset / software companion package

**Creator(s):** AUTHOR-CONTROLLED — use final manuscript author list and ORCIDs.

**Description:**

Analysis-ready data tables, metadata, code and frozen derived outputs supporting the Ecology Letters Letter “Access constraints reroute floral exploitation across bird and insect visitor networks.” The package reproduces the all-Ecuador bird–flower routing analysis at 259 plant species from 2,265 anonymous bird × plant × site aggregation units, paired and continuous within-bird checks, and the pre-frozen zero-inclusive participation analysis from 19,909 anonymous clean-waypoint × locally available bird opportunities (barrier/access total route-resolved exploitation rate ratio 1.7717; 95% plant-cluster jackknife CI 1.105–2.841). It also reproduces the independent 57-species Afrotropical insect corroboration, the equal-network routing test (rho_J = 0.4282), and the post hoc mechanism audit of opposite/mixed formal-frame boundary cases. Anonymous waypoint, plant- and bird-species identifiers preserve the fixed-effect and dependence structure without redistributing source taxon labels. Underlying source data are publicly archived by their original authors at Zenodo DOI 10.5281/zenodo.8398202 and Zenodo DOI 10.5281/zenodo.14185547.
