# Route-blind Cape third-network feasibility form v1

Thank you for considering the prospective small-mammal × Protea collaboration.

This form is intentionally limited to **route-blind feasibility** because the
third-network access-routing estimand has already been preregistered.

## Please do not include before the confirmatory site/plant list is frozen

Please do **not** provide unpublished or site/species-specific information about:

- which Protea species are more often accessed laterally, destructively, or by
  another non-legitimate route;
- which mammal species show more non-legitimate access;
- which sites show more non-legitimate access;
- route-specific event counts or proportions;
- access-mismatch × route coefficients, plots, p-values, or model results.

Published generic evidence that small mammals can use more than one access route
is already sufficient for method feasibility and does not need to be repeated.

### 3. Small-mammal richness

Without reference to flower-handling route:

- Which non-flying mammal species are documented or expected in the candidate
  sites?
- What is the evidence source (independent mammal survey, trapping records,
  camera inventory, museum/local faunal records, etc.)?
- Is a pool of at least five identifiable mammal species plausible?

### 4. Mammal morphology

- Are regional specimens or independent morphometric records available?
- Could a predeclared functional rostral-reach measurement be obtained without

- Would live capture be necessary, optional, or avoidable?

## Outcome-blindness note

The final site and plant list will be frozen from the route-blind information
above. Confirmatory route videos will only be opened after that freeze.

If historical route-specific information is accidentally shared, the affected
site/species is marked outcome-exposed and is not used to select the
confirmatory system.
